# 2026-11-14

## Backend milestone — Trend Detective (branch `backend`)

Built the complete mock-first FastAPI backend in `backend/` (18 endpoints, 121 passing
tests). Nothing committed or pushed; all changes are untracked on branch `backend`.

Key decisions worth remembering:

- Canonical variable ids come from `docs/architecture/scope.v2.json`
  (`air_temperature`, `soil_moisture`, `precipitation`, `vegetation_greenness`) and
  regions are `nile_corridor`, `morocco_comparison`, `sahel_comparison`.
  The brief's `egypt` / `ndvi` are handled as input aliases only.
- Region bbox conflict: `runtime_catalog.json` says `[24,22,36,32]`,
  `scope.v2.json` says `[29,24,33,32]`. scope.v2 wins; recorded in
  `backend/docs/OPEN_QUESTIONS.md`.
- All 12 registry entries have `method_ready=false` / `app_available=false`, so analyses
  run through a separate mock gate (`demo_available`) while the verified flags stay
  truthful.
- Trend slope bug found and fixed: monthly OLS let the seasonal cycle alias into the
  trend (0.035 configured rendered as 0.072). Switched to OLS on annual means of
  complete calendar years. Also added a per-variable flat threshold so near-zero slopes
  report `inconclusive` instead of a fake direction.
- FastAPI 0.163 ignores `AfterValidator` on query params; month query params need an
  explicit `pattern`.
- venv lives at repo root `.venv` (gitignored); run tests with
  `../.venv/Scripts/python.exe -m pytest` from `backend/`.
